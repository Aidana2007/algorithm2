This project is part of a university assignment where we had to create our own data structures in Java without using built-in Java classes like `ArrayList`, `LinkedList`, `Stack`, etc. The only thing we are allowed to use from `java.util` is `Iterator`.

We had to implement our own versions of:

- `MyArrayList` 
- `MyLinkedList` 
- `MyStack` 
- `MyQueue` 
- `MyMinHeap` 

All of them are generic and support any type of data.
